Bảng theo dõi công việc dùng chung. Tick lưu lên server — cả team thấy cùng một tiến độ.

Chưa nhập tên Đang tải tiến độ…

Upload file HTML làm checklist mới

Chọn file .html ở máy — nội dung hạng mục được đọc ra và lưu lên server, không cần push repo, không cần chờ deploy. Nhận hai dạng file: file khai SECTIONS (như webnovel-vn.html), hoặc file viết tay có mỗi hạng mục là một ô <input type="checkbox"> kèm tiêu đề. Mã checklist suy từ tên file nếu file không tự khai.

Đăng ký checklist đã có trong repo

File HTML phải đã nằm ở gốc repo (đã push lên GitHub). Form này chỉ đăng ký nó để hiện ở đây và cho phép ghi tick — nó không tạo ra file.

Cách dùng: mở checklist, nhập tên một lần, rồi tick. Tên hiện cạnh mỗi hạng mục để cả team biết ai đã làm việc gì. Số % ở đây đọc trực tiếp từ server, không phải từ máy bạn.

Thêm checklist mới: copy webnovel-vn.html ở máy, sửa CHECKLIST_ID và dữ liệu hạng mục, rồi bấm ⬆ Upload file HTML ở trên. Không cần push repo. Muốn sửa nội dung về sau thì upload lại chính file đó — tick đã có vẫn giữ nguyên.

+ Đăng ký file trong repo là cách cũ, dành cho file đã push lên GitHub và tự render lấy (như webnovel-vn.html). Xem README.md.
